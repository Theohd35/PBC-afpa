# La Plomberie

Application pédagogique statique dédiée aux plombiers chauffagistes en formation. Elle regroupe un catalogue d'accessoires sanitaires, un mémo de lecture de plan et des quiz aléatoires avec correction.

## Lancer le site

```bash
python3 -m http.server 8000
```

Puis ouvrir <http://localhost:8000>.

## Fonctionnalités

- 24 fiches métier filtrables et recherchables ;
- conseils de pose, contrôle et représentation sur plan ;
- plan sanitaire annoté et mémo en huit étapes ;
- 126 questions générées et rédigées, classées par thème ;
- quatre modes : mixte, QCM, réponse écrite et reconnaissance de symboles ;
- ordre des questions et réponses mélangé à chaque partie ;
- symboles schématiques vectoriels usuels, affichés avec le rappel de toujours consulter la légende du projet ;
- meilleur score conservé dans le navigateur.
